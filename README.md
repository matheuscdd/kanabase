O código-fonte desta aplicação (JavaScript, CSS puro e lógica dos Service Workers) é de autoria própria e distribuído sob a licença [MIT] *(ou a licença da sua escolha)*.

No entanto, os bancos de dados estáticos em JSON utilizados para alimentar o vocabulário e os conceitos desta aplicação foram estruturados, cruzados e adaptados a partir de fontes de terceiros, estando sujeitos às suas respectivas licenças abertas:

Aqui está a formatação para esse novo repositório, seguindo o mesmo padrão dos anteriores. Como ele também utiliza dados derivados da Arphic Technology, a licença é a mesma (Arphic Public License).

* **Hanzi Writer Data:** Dados de traços e ordem de escrita baseados no projeto Make Me A Hanzi, obtidos através do repositório [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data). Estes dados derivam de fontes originais da Arphic Technology e são redistribuídos sob a [Arphic Public License](https://www.google.com/search?q=https://github.com/chanind/hanzi-writer-data/blob/master/ARPHICPL.TXT).

**Sua lista completa e atualizada de créditos ficaria assim:**

* **JMdict:** Os dados de vocabulário japonês foram estruturados a partir do arquivo JMdict, propriedade do [Electronic Dictionary Research and Development Group (EDRDG)](http://www.edrdg.org/).
* **Wiktionary:** Definições e dados complementares adaptados do [Wiktionary](https://www.wiktionary.org/) (Fundação Wikimedia) e de seus contribuidores.
* **OpenWordnet-PT:** Relações semânticas e mapeamento de lemas providos pelo projeto [OpenWordnet-PT](https://github.com/own-pt) e pelo Princeton WordNet.
* **Dicionário Aberto:** Definições de conceitos em língua portuguesa extraídas do [Dicionário Aberto](https://dicionario-aberto.net/), um projeto de Alberto Simões baseado no dicionário de Cândido de Figueiredo.
* **AnimCJK (hanzi-writer-data-ja):** Os dados de traços e ordem de escrita dos caracteres japoneses (kanji) são provenientes do projeto AnimCJK, obtidos através do repositório [hanzi-writer-data-ja](https://www.google.com/search?q=https://github.com/mnako/hanzi-writer-data-ja/tree/master). Estes dados são disponibilizados sob a [Arphic Public License](https://www.google.com/search?q=https://github.com/mnako/hanzi-writer-data-ja/tree/master/APL).
* **Kana-JSON:** Dados estruturados dos caracteres silábicos japoneses (Hiragana e Katakana) obtidos a partir do repositório [kana-json](https://www.google.com/search?q=https://github.com/ailectra/kana-json/tree/main), mantido por Ailectra. Como o próprio repositório declara, os dados são baseados no projeto AnimCJK e, portanto, estão sujeitos aos termos da [Arphic Public License](https://www.google.com/search?q=https://github.com/mnako/hanzi-writer-data-ja/tree/master/APL).
* **Hanzi Writer Data:** Dados de traços e ordem de escrita baseados no projeto Make Me A Hanzi, obtidos através do repositório [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data). Estes dados derivam de fontes originais da Arphic Technology e são redistribuídos sob a [Arphic Public License](https://www.google.com/search?q=https://github.com/chanind/hanzi-writer-data/blob/master/ARPHICPL.TXT).
