## ⚖️ Licenças e Créditos de Dados

O código-fonte desta aplicação (JavaScript, CSS puro e lógica dos Service Workers) é de autoria própria e distribuído sob a licença [MIT] *(ou a licença da sua escolha)*.

No entanto, os bancos de dados estáticos em JSON utilizados para alimentar o vocabulário e os conceitos desta aplicação foram estruturados, cruzados e adaptados a partir de fontes de terceiros, estando sujeitos às suas respectivas licenças abertas:

* **JMdict:** Os dados de vocabulário japonês foram estruturados a partir do arquivo JMdict, propriedade do [Electronic Dictionary Research and Development Group (EDRDG)](http://www.edrdg.org/).
* **Wiktionary:** Definições e dados complementares adaptados do [Wiktionary](https://www.wiktionary.org/) (Fundação Wikimedia) e de seus contribuidores.
* **OpenWordnet-PT:** Relações semânticas e mapeamento de lemas providos pelo projeto [OpenWordnet-PT](https://github.com/own-pt) e pelo Princeton WordNet.
* **Dicionário Aberto:** Definições de conceitos em língua portuguesa extraídas do [Dicionário Aberto](https://dicionario-aberto.net/), um projeto de Alberto Simões baseado no dicionário de Cândido de Figueiredo.

**Licença dos Dados Derivados:** Como as fontes originais exigem o compartilhamento pela mesma licença (ShareAlike), o arquivo JSON consolidado que é consumido pela interface e armazenado no cache offline do navegador é distribuído sob a licença [Creative Commons Attribution-ShareAlike (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/).
