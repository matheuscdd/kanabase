# First conditional para possibilidades reais no futuro

## Resumo
Usamos o first conditional para falar de situações possíveis no futuro e de seus resultados prováveis. A condição vai no presente simples e o resultado costuma usar `will`.

## Explicação
Essa estrutura serve para situações reais ou prováveis, não imaginárias. Quando a condição acontecer, o resultado provavelmente também acontecerá.

No B1, o aluno deve perceber a diferença entre fatos gerais do zero conditional e possibilidades futuras do first conditional.

## Estrutura
- If + present simple, will + base verb
- Will + base verb + if + present simple

## Exemplos
- If it rains tomorrow, we will stay home.
  Tradução: Se chover amanhã, nós vamos ficar em casa.
- If you study harder, you will pass the exam.
  Tradução: Se você estudar mais, vai passar na prova.
- She will call you if she arrives early.
  Tradução: Ela vai ligar para você se chegar cedo.
- If we miss the bus, we will take a taxi.
  Tradução: Se perdermos o ônibus, vamos pegar um táxi.
- If they invite me, I will go.
  Tradução: Se eles me convidarem, eu vou.

## Observações
- Não usamos `will` na oração com `if`.
- A estrutura fala de uma possibilidade considerada real.

## Erros comuns
- Errado: If it will rain, we will stay home.
- Certo: If it rains, we will stay home.
- Errado: If you study, you pass the exam tomorrow.
- Certo: If you study, you will pass the exam tomorrow.

## Prática
1. Complete: `If he finishes early, he ___ us. (join)`
2. Complete: `We will buy the tickets if they ___ cheap. (be)`
3. Traduza: `Se ela ligar, eu vou responder.`
