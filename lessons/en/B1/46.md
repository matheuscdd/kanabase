# Conectores de propósito com so that e in order to

## Resumo
Usamos `so that` e `in order to` para expressar propósito. Eles mostram por que alguém faz alguma coisa.

## Explicação
`In order to` é seguido de verbo na forma base. `So that` introduz uma oração completa, normalmente com sujeito e verbo modal ou verbo comum.

No B1, esses conectores ajudam a escrever com mais clareza sobre objetivos e intenções.

## Estrutura
- subject + verb + in order to + base verb
- subject + verb + so that + clause

## Exemplos
- I left early in order to catch the bus.
  Tradução: Eu saí cedo para pegar o ônibus.
- She spoke slowly so that everyone could understand.
  Tradução: Ela falou devagar para que todos pudessem entender.
- We saved money in order to travel next year.
  Tradução: Nós economizamos dinheiro para viajar no próximo ano.
- He wrote the address down so that he wouldn't forget it.
  Tradução: Ele anotou o endereço para não esquecê-lo.
- They turned off the TV in order to study.
  Tradução: Eles desligaram a TV para estudar.

## Observações
- `In order to` é seguido por verbo, não por oração completa.
- `So that` é seguido por sujeito + verbo.

## Erros comuns
- Errado: I left early in order that catch the bus.
- Certo: I left early in order to catch the bus.
- Errado: She spoke slowly so that understand.
- Certo: She spoke slowly so that everyone could understand.

## Prática
1. Complete: `He is studying hard in order to ___ the exam. (pass)`
2. Complete: `She whispered so that nobody ___ her. (hear)`
3. Traduza: `Nós saímos cedo para evitar trânsito.`

## Gabarito
1. pass
2. would hear / could hear
3. We left early in order to avoid traffic.
