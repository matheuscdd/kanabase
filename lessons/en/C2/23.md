# Contrafactuais complexos no período condicional

## Resumo
Contrafactuais complexos expressam situações irreais em que tempos, resultados e perspectivas podem pertencer a momentos diferentes.

## Explicação
No C2, o período condicional vai além dos modelos tradicionais. É comum combinar uma condição irreal no passado com consequência no presente, ou uma condição irreal no presente com consequência situada no passado. Essas combinações são chamadas de conditionals mistos ou complexos.

O falante escolhe os tempos verbais para mostrar exatamente onde está a irrealidade e onde está o efeito. Isso permite análises mais precisas sobre causa, responsabilidade e consequência.

## Estrutura
- If + past perfect, would/could/might + base verb
- If + past simple, would/could/might + have + past participle
- Mixed conditionals may combine present and past reference in different ways

## Exemplos
- If the warning had been taken seriously, we would not be facing this crisis now.
  Tradução: Se o aviso tivesse sido levado a sério, não estaríamos enfrentando esta crise agora.
- If he were better prepared, he would have handled the interview more effectively yesterday.
  Tradução: Se ele fosse mais bem preparado, teria lidado melhor com a entrevista ontem.
- If the system were more transparent, the error might have been detected earlier.
  Tradução: Se o sistema fosse mais transparente, o erro talvez tivesse sido detectado antes.
- Had they not expanded so aggressively, the company might still be solvent.
  Tradução: Se eles não tivessem expandido de forma tão agressiva, a empresa talvez ainda fosse solvente.
- If she had not been so cautious, the negotiations could have collapsed.
  Tradução: Se ela não tivesse sido tão cautelosa, as negociações poderiam ter fracassado.

## Observações
- O tempo verbal revela onde está a hipótese irreal e onde está o efeito.
- Conditionals mistos são muito úteis para interpretar responsabilidade e resultado.
- O uso de `might` e `could` permite nuance adicional de possibilidade.

## Erros comuns
- Errado: If the warning had been taken seriously, we would not face this crisis now.
- Certo: If the warning had been taken seriously, we would not be facing this crisis now.
- Errado: If he were better prepared, he would have handle the interview better.
- Certo: If he were better prepared, he would have handled the interview better.

## Prática
1. Complete: `If they had acted sooner, the damage ___ smaller now. (be)`
2. Reescreva como condicional misto: `She is not more careful, so she made a serious mistake yesterday.`
3. Traduza: `Se eu tivesse ouvido você, não estaria com esse problema agora.`

## Gabarito
1. would be
2. If she were more careful, she would not have made such a serious mistake yesterday.
3. If I had listened to you, I would not be dealing with this problem now.
