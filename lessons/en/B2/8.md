# If only para reforçar desejos e arrependimentos

## Resumo
Usamos `if only` para expressar desejos e arrependimentos de forma mais enfática do que `wish`. A estrutura gramatical costuma seguir os mesmos padrões de `wish`.

## Explicação
`If only` pode se referir ao presente, ao futuro ou ao passado, dependendo do tempo verbal usado. A diferença principal está no tom: essa expressão costuma soar mais emocional e enfática.

No B2, ela é útil para dar mais força a reclamações, frustrações e arrependimentos.

## Estrutura
- If only + past simple
- If only + past perfect
- If only + would + base verb

## Exemplos
- If only I had more time.
  Tradução: Se ao menos eu tivesse mais tempo.
- If only she were here now.
  Tradução: Se ao menos ela estivesse aqui agora.
- If only we had left earlier.
  Tradução: Se ao menos tivéssemos saído mais cedo.
- If only he would listen to me.
  Tradução: Se ao menos ele me ouvisse.
- If only they hadn't missed the train.
  Tradução: Se ao menos eles não tivessem perdido o trem.

## Observações
- `If only` é mais expressivo que `wish`.
- Com `would`, a estrutura costuma expressar irritação ou desejo de mudança de comportamento.

## Erros comuns
- Errado: If only I have more time.
- Certo: If only I had more time.
- Errado: If only she didn't miss the train yesterday.
- Certo: If only she hadn't missed the train yesterday.

## Prática
1. Complete: `If only he ___ more careful now. (be)`
2. Complete: `If only I had ___ the truth. (know)`
3. Traduza: `Se ao menos ela me escutasse.`
