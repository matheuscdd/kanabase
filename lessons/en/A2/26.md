# Should e shouldn't para conselhos

## Resumo
Usamos `should` para dar conselhos e `shouldn't` para dizer que algo não é uma boa ideia. É uma estrutura muito comum para recomendações simples.

## Explicação
`Should` é mais suave do que `must`. Ele indica opinião, sugestão ou conselho. `Shouldn't` indica que algo é melhor evitar.

No A2, esse conteúdo é muito útil para saúde, estudos, hábitos e problemas do dia a dia.

## Estrutura
- Subject + should + base verb
- Subject + shouldn't + base verb

## Exemplos
- You should go to bed earlier.
  Tradução: Você deveria ir dormir mais cedo.
- She should study more for the test.
  Tradução: Ela deveria estudar mais para a prova.
- We should call him.
  Tradução: Nós deveríamos ligar para ele.
- You shouldn't eat so much sugar.
  Tradução: Você não deveria comer tanto açúcar.
- He shouldn't drive when he is tired.
  Tradução: Ele não deveria dirigir quando está cansado.

## Observações
- Depois de `should`, o verbo fica na forma base.
- `Should` é usado para conselho, não para obrigação forte.

## Erros comuns
- Errado: You should to rest.
- Certo: You should rest.
- Errado: He shouldn't drives at night.
- Certo: He shouldn't drive at night.

## Prática
1. Complete: `You should ___ more water. (drink)`
2. Complete: `She shouldn't ___ so late. (sleep)`
3. Traduza: `Nós deveríamos sair agora.`
