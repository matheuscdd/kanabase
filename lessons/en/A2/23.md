# Would like para vontades e ofertas

## Resumo
Usamos `would like` para falar de vontades de forma educada e para fazer ofertas e convites. É mais polido do que usar apenas `want` em muitas situações.

## Explicação
`Would like` pode ser seguido por um substantivo ou por `to + verbo`. Dizemos `I would like some coffee` e `She would like to travel`.

No A2, essa estrutura é importante para restaurantes, convites, pedidos e situações formais simples.

## Estrutura
- Subject + would like + noun
- Subject + would like + to + verb

## Exemplos
- I would like some tea.
  Tradução: Eu gostaria de um pouco de chá.
- She would like to visit London.
  Tradução: Ela gostaria de visitar Londres.
- We would like a table for two.
  Tradução: Nós gostaríamos de uma mesa para dois.
- He would like to speak to the manager.
  Tradução: Ele gostaria de falar com o gerente.
- Would you like some cake?
  Tradução: Você gostaria de um pouco de bolo?

## Observações
- `Would like` é uma forma educada.
- Depois de verbo, usamos `to + infinitivo`.

## Erros comuns
- Errado: I would like buy a car.
- Certo: I would like to buy a car.
- Errado: She would like a travel.
- Certo: She would like to travel.

## Prática
1. Complete: `He would like ___ a new phone. (buy)`
2. Complete: `We would like ___ coffee.`
3. Traduza: `Ela gostaria de falar com você.`

## Gabarito
1. to buy
2. some
3. She would like to speak to you.
