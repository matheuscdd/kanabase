# Julgar pela primeira impressão com 〜からして

## Resumo
`〜からして` indica julgamento a partir de um aspecto inicial ou evidente. No N1, equivale a `só pelo`, `a julgar por`, `começando por`.

## Explicação
O falante toma um elemento visível, audível ou imediatamente perceptível como base para avaliação. Também pode significar que certo item, por si só, já exemplifica o conjunto.

É comum em avaliações, descrições e críticas.

## Estrutura
- Substantivo + からして
- Sentido de julgar a partir de um ponto inicial
- Pode equivaler a `só pela aparência`, `a começar por`

## Exemplos
- かれは くちょうからして いばっている。
  Romaji: kare wa kuchou kara shite ibatte iru.
  Tradução: Só pelo jeito de falar dele, já dá para ver que é arrogante.
- この みせは みためからして ふつうではない。
  Romaji: kono mise wa mitame kara shite futsuu de wa nai.
  Tradução: Só pela aparência, esta loja já não é comum.
- かのじょは ふくそうからして プロの かんじがする。
  Romaji: kanojo wa fukusou kara shite puro no kanji ga suru.
  Tradução: Pela roupa dela, já parece uma profissional.
- あの ひとの たいどからして、しんらいしにくい。
  Romaji: ano hito no taido kara shite, shinrai shinikui.
  Tradução: A julgar pela atitude daquela pessoa, é difícil confiar nela.
- この けんは はじまりからして おかしかった。
  Romaji: kono ken wa hajimari kara shite okashikatta.
  Tradução: Esse caso já estava estranho desde o começo.

## Observações
- `〜からして` toma um ponto inicial como base para avaliar o todo.
- Pode ter nuance crítica ou simplesmente observacional.

## Erros comuns
- Errado: Usar sem base clara de julgamento.
- Certo: Precisa haver um indício visível ou ponto inicial concreto.
- Errado: Confundir com simples origem física.
- Certo: Aqui o sentido principal é avaliação.

## Prática
1. Traduza: `Só pelo jeito de falar dele, já dá para ver.`
2. Traduza: `Pela aparência, esta loja não é comum.`
3. Escreva em romaji: `みためからして`

## Gabarito
1. くちょうからして わかる。
2. みためからして ふつうではない。
