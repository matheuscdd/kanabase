# Se não for este caso excepcional com 〜ならいざしらず

## Resumo
`〜ならいざしらず` indica que, se fosse um certo caso excepcional, até se entenderia, mas fora disso não. No N1, equivale a `se fosse X, ainda vai`, `mas se não for isso...`.

## Explicação
O falante estabelece um caso especial que poderia ser aceitável e depois mostra que a situação real não entra nessa exceção. A estrutura é muito útil para crítica, comparação e julgamento.

Ela costuma aparecer com contraste entre um caso extremo aceitável e outro menos justificável.

## Estrutura
- Frase / substantivo + ならいざしらず
- Sentido de exceção limitada seguida de crítica ou negação
- Equivale a `se fosse isso, até vai, mas...`

## Exemplos
- こどもなら いざしらず、おとなが そんなことを するのは おかしい。
  Romaji: kodomo nara iza shirazu, otona ga sonna koto o suru no wa okashii.
  Tradução: Se fosse criança, tudo bem, mas um adulto fazer isso é estranho.
- いちどだけなら いざしらず、なんども くりかえすのは ゆるせない。
  Romaji: ichido dake nara iza shirazu, nando mo kurikaesu no wa yurusenai.
  Tradução: Se fosse só uma vez, ainda vai, mas repetir tantas vezes é imperdoável.
- きゅうようなら いざしらず、りゆうもなく やすむのは まずい。
  Romaji: kyuuyou nara iza shirazu, riyuu mo naku yasumu no wa mazui.
  Tradução: Se fosse urgência, ainda se entenderia, mas faltar sem motivo é ruim.
- はじめてなら いざしらず、けいけんしゃが まちがえるのは もんだいだ。
  Romaji: hajimete nara iza shirazu, keikensha ga machigaeru no wa mondai da.
  Tradução: Se fosse a primeira vez, ainda se entenderia, mas um experiente errar é problemático.
- むかしなら いざしらず、いま その かんがえは とおらない。
  Romaji: mukashi nara iza shirazu, ima sono kangae wa tooranai.
  Tradução: Se fosse antigamente, talvez, mas hoje essa ideia não passa.

## Observações
- `〜ならいざしらず` cria um contraste entre exceção admissível e caso real criticado.
- O tom é argumentativo e muitas vezes crítico.

## Erros comuns
- Errado: Usar sem contraste real entre caso excepcional e caso atual.
- Certo: A força da estrutura está justamente nesse contraste.
- Errado: Tratar como condicional neutro.
- Certo: Há julgamento implícito na segunda parte.

## Prática
1. Traduza: `Se fosse criança, ainda vai, mas adulto não.`
2. Traduza: `Se fosse só uma vez, tudo bem, mas repetir é demais.`
3. Escreva em romaji: `ならいざしらず`
