# A partir de base ou princípio com 〜のもとに

## Resumo
`〜のもとに` indica que algo se realiza tendo certa base, principio, ideia ou orientaçao. No N2, equivale a `sob`, `com base em`, `guiado por`.

## Explicação
Ela se aproxima de `〜のもとで`, mas `〜のもとに` costuma soar mais abstrata, enfatizando principio, conceito, orientaçao ou liderança como fundamento.

O foco esta menos no ambiente de execuçao e mais na base que orienta o que se faz.

## Estrutura
- Substantivo + のもとに
- Sentido de base, principio ou orientaçao
- Equivale a `sob a orientaçao de`, `com base em`

## Exemplos
- せんせいの しどうの もとに、ろんぶんを まとめた。
  Romaji: sensei no shidou no moto ni, ronbun o matometa.
  Tradução: Organizei o artigo sob a orientaçao do professor.
- きょうりょくの りねんの もとに、プロジェクトが はじまった。
  Romaji: kyouryoku no rinen no moto ni, purojekuto ga hajimatta.
  Tradução: O projeto começou com base no ideal de cooperaçao.
- ほうりつの もとに、この せいどが うんようされている。
  Romaji: houritsu no moto ni, kono seido ga unyou sarete iru.
  Tradução: Este sistema esta sendo operado com base na lei.
- めいかくな もくひょうの もとに、けいかくを たてた。
  Romaji: meikaku na mokuhyou no moto ni, keikaku o tateta.
  Tradução: Fizemos o plano com base em um objetivo claro.
- その かんがえの もとに、あたらしい せいさくが つくられた。
  Romaji: sono kangae no moto ni, atarashii seisaku ga tsukurareta.
  Tradução: A nova politica foi criada com base nessa ideia.

## Observações
- `〜のもとに` destaca base abstrata, principio ou orientaçao.
- E muito natural em textos formais e institucionais.

## Erros comuns
- Errado: Tratar como simples local fisico.
- Certo: Aqui o foco e fundamento ou diretriz.
- Errado: Confundir totalmente com `〜をもとに`.
- Certo: `〜のもとに` enfatiza enquadramento; `〜をもとに` enfatiza usar algo como material-base.

## Prática
1. Traduza: `O projeto começou com base no ideal de cooperaçao.`
2. Traduza: `O sistema opera com base na lei.`
3. Escreva em romaji: `のもとに`
